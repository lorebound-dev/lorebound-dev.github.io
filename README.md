# LOREBOUND test site

Test builds of LOREBOUND, played at **https://lorebound-dev.github.io/**. The real game is at https://lorebound-game.github.io/.

This repository holds one test build at a time, from a pull request in the private `lorebound-game/LOREBOUND` repository. `.github/workflows/publish-test.yml` there replaces everything here with each test build, so make changes there, not here. The test site has its own address, so its saves never mix with the real game's.
